# 곤상플랜

## 로컬 실행

1. `.env.example`을 복사해 `.env` 파일을 만들고 Amadeus 테스트 API Key와 Secret을 입력합니다.
2. `npm start`를 실행합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다.

API 인증 정보는 브라우저 HTML에 포함하지 않고 로컬 서버에서만 사용합니다. Amadeus 키가 없으면 화면은 열리지만 실제 운임 검색은 동작하지 않습니다.

## Amadeus 테스트 환경 참고

Amadeus 테스트 환경은 실제 시장 전체를 반영하는 실시간 운임 데이터가 아니라 제한된 테스트 데이터와 월간 호출 한도를 제공합니다. Amadeus 개발자 안내에는 Self-Service 개발자 포털이 2026년 7월 17일 종료되었다고 표시되어 있어, 새 테스트 키 발급 가능 여부를 먼저 확인해야 합니다. 유효한 기존 테스트 키가 있는 경우 이 화면에서 사용할 수 있습니다.
