# 곤상플랜

**곤상플랜 : 당신의 여행을 곤상에게 맡기세요!**

여행지와 날짜, 인원만 정하면 항공 · 숙소 · 관광 · 맛집을 한 화면에서 고르고, 예산을 확인하고, 최종 여행 계획까지 한 번에 정리해 주는 여행 플래너 웹 서비스입니다.

## 주요 기능

- **여행 조건 설정** : 여행지, 날짜, 여행자를 고르면 항공 · 숙소 · 관광 · 맛집 탭이 같은 조건으로 연동됩니다.
- **항공 · 숙소 · 관광 · 맛집 탐색** : 탭마다 조건을 정해 후보를 찾고, 마음에 드는 곳을 골라 담습니다.
- **실시간 예산 관리** : 고른 항목의 금액이 예산 패널에 바로 합산되고, 목표 예산과 1인당 금액(N빵), 원화/외화 환산을 확인할 수 있습니다.
- **최종 일정 정리** : 고른 내용으로 날짜별 달력형 일정표, 예상 경비, 국가별 출국 준비 체크리스트, 여행 날씨를 보여 줍니다.

> 항공 · 맛집 결과 등 일부 화면은 아직 모의(데모) 또는 샘플 데이터입니다. 실제 가격과 예약 정보는 각 서비스에서 확인해 주세요.

## 로컬 실행

1. `.env.example`을 복사해 `.env` 파일을 만들고 Amadeus 테스트 API Key와 Secret을 입력합니다.
2. `npm start`를 실행합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다.

API 인증 정보는 브라우저 HTML에 포함하지 않고 로컬 서버에서만 사용합니다. Amadeus 키가 없으면 화면은 열리지만 실제 운임 검색은 동작하지 않습니다.

## Amadeus 테스트 환경 참고

Amadeus 테스트 환경은 실제 시장 전체를 반영하는 실시간 운임 데이터가 아니라 제한된 테스트 데이터와 월간 호출 한도를 제공합니다. Amadeus 개발자 안내에는 Self-Service 개발자 포털이 2026년 7월 17일 종료되었다고 표시되어 있어, 새 테스트 키 발급 가능 여부를 먼저 확인해야 합니다. 유효한 기존 테스트 키가 있는 경우 이 화면에서 사용할 수 있습니다.
